# Digital Online Shopping System
## Software Engineering and Project Management (SEPM)

### Project Overview
This project focuses on the Software Requirements Specification (SRS) for a Digital Online Shopping System. It documents system requirements, user roles, UML diagrams, testing plans, feasibility analysis, risk assessment, and project cost estimation.

### Objectives
- Define functional and non-functional requirements.
- Represent the system using UML diagrams.
- Prepare test cases and project planning documentation.
- Apply software engineering principles to system design.
